# F2 日历定时 provider 模板

基线：`origin/feat/1009-cx3-f1-range-breakout`，`0157c0bccc1d2ffccd15a71d1d7c6dab4ea9ec29`。独立分支 `feat/1009-cx3-f2-calendar`，不跟踪上游。只交付 provider、离线本地验收和说明；未开 PR、未合 main，未做服务端注册、Pre 或生产验证。

工具：`local.backtesting_py.calendar_schedule`。挂共享风控 mixin 和 `_with_time_config`；日历固有开/平仓时钟独立于可选时间门禁。默认未配置开仓时刻时不交易。配置了开仓时刻必须同时配置持有分钟或定时平仓，两个出场条件都有时先到者生效。

## 参数

| 键 | 类型 / 默认 | 约束和消费 |
| --- | --- | --- |
| `time_entry_at` | string / `""` | 严格 HH:MM；空串不交易 |
| `time_entry_weekday` | integer / -1 | -1 表示每日；0–6 表示周一至周日 |
| `time_entry_monthday` | integer / 0 | 0 表示不限制；1–31 指定月日；与星期互斥；小月缺日跳过 |
| `direction` | string / long | long、short；spot 的 short 在取数前拒绝；both 不支持 |
| `time_timezone` | string / UTC | 有效 IANA；同时决定开仓、强平、星期和月日 |
| `time_max_holding_minutes` | integer / 0 | 0–525600；实际成交 UTC 时间起算；小时数乘 60；0 关闭 |
| `time_flatten_at` | string / `""` | 严格 HH:MM；空串关闭 |
| `time_flatten_weekdays` | integer / 127 | 1–127，bit0 周一；非默认必须配强平时刻 |
| `calendar_stop_enabled` | boolean / true | 严格 bool；false 关闭默认止损，此时显式止损比例冲突拒绝 |
| `stop_loss_pct` | number / 3 | 0 < 值 < 100；信号收盘时冻结；不可表示的小比例拒绝 |
| `take_profit_pct` | number / 无 | 可选共享百分比止盈，按实际成交价冻结 |
| `position_size_pct` / `position_size_notional` | number / 无 | 共享固定百分比或名义仓位，两者互斥 |
| `risk_layer_enabled` / `max_holding_bars` | boolean false / integer 0 | 复用共享启用契约与成交根计数；risk 或可选 time 启用才消费非零根数 |
| `time_layer_enabled` | boolean / false | 只控制额外的时段/星期入场门禁；不关闭模板固有日历时钟 |
| `time_session_start` / `time_session_end` / `time_weekdays` | `""` / `""` / 127 | 共享可选时间门禁，非默认需要 `time_layer_enabled=true`；只限开仓 |
| `leverage` | integer / 1 | 沿用单仓 provider 现有门禁，当前仅支持 1 |

不开启未消费的 ATR、移动/保本止损、多档止盈参数；schema 与运行时拒绝保持一致。三个日历入口键仅挂本模板，不扩到旧工具。`time_timezone`、分钟上限和强平键是本模板固有参数，可在可选时间层关闭时配置。

示例：每周五 UTC 20:00 开多，下周一 UTC 08:00 平仓：

```json
{"time_entry_at":"20:00","time_entry_weekday":4,"time_flatten_at":"08:00","time_flatten_weekdays":1,"time_timezone":"UTC","direction":"long"}
```

## 执行裁定

- codex-3 定：决策时刻是本根开盘 + 周期；事件等于收盘边界时提交，下一根开盘市价成交。例如 19:00 开的 1h 根在 20:00 决策，成交在下一根 20:00 开盘；不使用信号根 19:00 的开盘价。第一根收盘到点也处理，仅读第一根已收盘价格，在引擎首次可成交开盘前提交。
- codex-3 定：开仓/强平时刻、持有分钟到期若切穿 K 线，取数前拒绝。仅支持固定 m/h/d/w 周期；行情缺根明确 `TIME_DATA_GAP`；不裁行情、不补虚构成交。
- codex-3 定：春季不存在的当地时刻跳过当天；秋季重复时刻只取 fold=0；31 日不改成小月最后一天。星期/月日未指定时为每日事件。
- codex-3 定：持仓中再到点记 `already_holding` 并跳过；止损 → 时间到期/强平 → 止盈；有持仓/出场订单时该根不重入、不反手。
- codex-3 定：默认 3% 止损在信号收盘冻结；当可成交开盘落在冻结止损错侧，成交前取消，并在 `raw_report.calendar_events` 记 `gap_stop_wrong_side`、可成交开盘和冻结止损；止损触及 High/Low 后仍是下一根开盘市价出场。冻结止损与实际成交后利润目标分别披露在 assumptions。
- codex-3 定：日历诊断只加 `raw_report`；assumptions 披露时区/tzdata、DST、成交/止损口径与引擎末尾结算。result.v2 的 trades、metrics、equity_curve、data_manifest 仍走既有构建器。

## 可编译变异

驱动脚本每项先备份，再单项写入、`py_compile`、独立进程 pytest，最后 copy 还原和 `cmp`；不使用 git checkout。失败都是业务结果断言，不是导入/语法错误；各 pytest 实际退出码 1，驱动退出码 0，各次 `cmp=0`。各项筛选表达式在脚本中固定。

| 变异 | 被拦住的直接结果 |

| M1 信号当根开盘就成交 | EntryBar 1 / 100，预期 EntryBar 2 / 104；long/short 均失败 |
