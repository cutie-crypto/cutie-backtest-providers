## codex-4 定

1. 两侧各 N 根严格极值；复用 9-P1 `strategy_swing_points.py`，只按确认下标消费。确认 H 的当根不入场，从后续收盘开始。
2. 同一根同时确认低点、高点时不虚构先后顺序：清掉候选波段，等待后续一对相邻 L→H。
3. 使用有限预热段与主区间拼接后的零起始下标；预热段不成交，但参与波段确认与收盘失效判断。新确认点即废弃旧候选；在持仓中仍更新候选事件，已持仓的冻结价格不变。
4. 涨幅门槛、档位和容差边界使用 Decimal；恰好等于门槛 / 容差边界放行，恰好等于止损的收盘不作触发前失效。
5. 价格风控键任一显式出现（包括显式 0 / false）即整组关闭模板默认价格；定额仓位、杠杆、时间与 risk_layer_enabled 开关不单独关闭默认价格。这与 F5 价格覆盖判据一致。结构性波段失效仍使用波段止损参考价。
6. 默认波段止损 / 止盈使用 High / Low 触碰，即使共享风控开关关闭；显式价格覆盖后的用户风控沿用共享层开关语义。启用层的优先级为止损 → 时间到期 / 定时平仓 → 止盈；成交统一下一根开盘。动态止损排除成交当根，复用共享层行为。
7. 买入信号生成即消耗该 L/H 对；跳空取消、引擎因资金不足未成交也不重试。下一根开盘 <= 冻结止损或 >= 冻结止盈时，在真实 broker 成交前取消并记录原因。
8. 最后一根不排新买单，已有仓位沿用引擎 finalize_trades 结算。原文可选吞没 / 锤子线确认未实现，assumptions 明示等待通用能力；下跌镜像做空留做空批。
